## 使用规则

- A 级：法律、司法解释、发布机关正式文件或原始同行评议论文；
- B 级：发布机关的权威说明、大学研究门户或正式会议论文；
- C 级：研究性评论，仅用于发现问题，不单独支撑系统规则；
- 本台账记录研究依据，不表示某一来源已经被完整编码为可执行规则。

## 关键结论与来源对应

| 结论 | 主要来源 |
|---|---|
| Carneades 可逐前提分配证明责任并表示批判性问题 | S01、S02、S03、S15 |
| Carneades 是通用论证模型，具体法律证明标准仍需领域建模 | S04 |
| 参数级 MoE 与系统级法律专家路由不是同一技术 | S05、S06、S07 |
| 中国民事“高度可能性”不能直接等同 PE | S08 |
| 中国刑事排除合理怀疑还受证据查证与程序条件约束 | S10、S19 |
| 电子数据应分真实性、完整性、提取合法性和推定反驳建模 | S09、S10、S11、S12 |
| 区块链不当然证明上链前内容真实 | S11、S12 |
| 司法 AI 必须保持辅助性和责任主体，且可解释、可测试、可验证 | S13 |
| 法律 NLP 需要与显式法律专业知识和论证结构融合 | S16、S17 |
