## 自动验收

```bash
go build -o bin/carneades ./src/cmd/carneades
go test -vet=off \
  ./src/cmd/carneades \
  ./src/engine/caes/encoding/yaml
./bin/carneades check -f yaml \
  examples/AGs/YAML/zh-CN/电子数据真实性.yml
```

全仓库 `go test ./...` 目前仍会被上游 Dung YAML、JS 模块的类型不一致、
`go vet` 格式错误以及 CouchDB 集成测试阻断。首轮汉化不得把这些上游问题标记为
本地化回归，也不得在未修复前声称全仓库测试通过。
