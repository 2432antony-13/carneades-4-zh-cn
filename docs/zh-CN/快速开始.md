# 快速开始

## 1. 环境

- Go 1.18 或更高版本；
- Graphviz，用于导出 PNG 和 SVG；
- 支持 UTF-8 的终端与浏览器。

## 2. 构建

```bash
go mod download
go test -vet=off \
  ./src/cmd/carneades \
  ./src/engine/caes/encoding/yaml
go build -o bin/carneades ./src/cmd/carneades
```

以上为当前中文研究分支的聚焦测试。上游遗留模块导致的全仓库测试限制见
[两日交付清单](两日交付清单.md)，不得据此声称 `go test ./...` 已全部通过。

## 3. 启动中文界面

```bash
./bin/carneades server \
  -p 8080 \
  -t ./src/web/templates \
  -l zh-CN
```

打开 `http://localhost:8080/carneades/`。

`-l en` 使用上游英文模板；`-l zh-CN` 使用本仓库的简体中文模板。

## 4. 检查中文 YAML

```bash
./bin/carneades check \
  -f yaml \
  examples/AGs/YAML/zh-CN/电子数据真实性.yml
```

具体命令参数以 `./bin/carneades help check` 的输出为准。

## 5. 评估并导出

```bash
./bin/carneades eval \
  -f yaml \
  -t graphml \
  examples/AGs/YAML/zh-CN/电子数据真实性.yml
```

也可以在中文 Web 页面上传 YAML，并选择 YAML、GraphML、DOT、PNG 或 SVG 输出。

## 6. 解释结果

- `in`：在当前论证图、前提状态和证明标准下可接受；
- `out`：在当前形式模型下不可接受；
- `undecided`：当前信息不足以确定；
- `weight`：论证权重函数的计算值，不是事实概率；
- `PE`、`CCE`、`BRD`：Carneades 的形式标准名称，不自动取得中国法上的规范效力。

## 7. 常见问题

### 中文显示正常，但图像中出现方框

这是 Graphviz 或查看器字体配置问题，不是 YAML 编码问题。为 Graphviz 配置可显示中文的字体后重新导出。

### 能否直接导入判决书

不能。Carneades 读取结构化论证图，而不是自动理解完整判决书。自然语言材料必须先经过事实抽取、来源绑定、论证关系确认和人工复核。

### 能否自动得出裁判结论

本地化版本不提供这一功能。它定位为论证结构整理、反驳检查、争点评估和说理辅助工具。
