# 中国语境适配范围与未完成事项

## 本阶段包含

- Web 首页、帮助页、论证图评估页和 Dung 框架计算页；
- 错误页、隐私说明和项目声明；
- 中文运行说明与核心术语；
- 中文 YAML 示例；
- 中文文本的 YAML 导入导出验证。
- CLES-MoE 中国证据推理研究报告、来源台账和架构契约；
- 对 `PE`、`CCE`、`BRD` 与中国证明标准的明确区分；
- 来源账本、事实账本和论证账本的研究 Schema。

## 本阶段不包含

- 将所有 Go 内部错误信息翻译为中文；
- 自动识别判决书和证据材料；
- 中国证据法完整知识库；
- 中国法证明责任与证明标准计算模块；
- 参数级神经 MoE 的训练和部署；
- 自动专家路由器、事实核验工作台和人工签署流程；
- 对原始论文图表或中文学术成果的再发布；
- 司法、检察或律所生产环境部署。

## 后续优先级

1. 实现来源账本、事实账本和确定性优先路由器；
2. 将形式证明标准与法域政策模块分离；
3. 实现中国民事电子数据真实性专家包；
4. 增加中国证明标准插件和真伪不明状态；
5. 将界面文本从模板中提取为可维护的语言资源；
6. 为 Graphviz 增加中文字体配置；
7. 建立中文案例标注集和专家一致性评测。
