# CLES-MoE 中国证据推理架构

本文件是研究报告的工程摘要。完整论证见
[中国证据推理 MoE 架构研究报告](../../research/zh-CN/中国证据推理MoE架构研究报告.md)。

## 架构定位

CLES-MoE 是本项目提出的中国证据论证专家混合架构：

- 神经模型负责读取材料并生成候选事实；
- 规则路由器根据法域、程序、阶段、证据类型和争点激活专家；
- 事实门只允许经人工核验的事实进入形式推理；
- Carneades 负责计算支持、反对、例外和截断关系；
- 人工复核者确认事实、法律解释和最终使用方式。

当前仓库实现的是中文界面、研究规范和 Carneades 符号内核适配基础，尚未训练参数级
神经 MoE。

## 不可绕过的共享专家

`S0 来源与事实账本`：记录材料定位、哈希、版本、事实状态和人工核验。  
`S1 引用与审计`：检查法源版本、跨法域混用、路由过程和自然语言越权。

## 第一批路由专家

| 专家 | 范围 |
|---|---|
| E1 | 中国民事证明责任、本证反证与证明标准 |
| E2 | 中国刑事证据资格、补正和排除 |
| E3 | 电子数据真实性、完整性和提取过程 |
| E4 | 证人证言、陈述和供述的批判性问题 |
| E5 | 鉴定意见与专家意见 |
| E6 | 印证关系、证据链和竞争解释 |
| E7 | 法律解释、规范效力和规则适用 |

## 最小处理顺序

1. 确认法域、程序、阶段和任务；
2. 建立来源账本；
3. 提取候选事实，不得自动确认；
4. 人工确认事实状态；
5. 规则路由器选择强制专家；
6. 专家生成批判性问题和论证型式；
7. 证据资格门先于证明力计算；
8. 构建并计算 Carneades 论证图；
9. 输出已核验事实、争议、缺失、依据、正反论证和未决项；
10. 人工复核并留下版本记录。

## 当前实现限制

- `PE`、`CCE`、`BRD` 是上游计算标准，尚不是中国证明标准插件；
- 当前争点解析器不能充分表达真伪不明和程序性排除；
- 当前示例中的已接受输入是教学环境下的人工核验模拟；
- 形式标签不等于证据采信、事实认定、胜诉概率或裁判结论。
