# Carneades 中英文术语表

| 英文 | 推荐中文 | 说明 |
|---|---|---|
| argument | 论证 | 从前提支持或反对结论的结构 |
| argument graph | 论证图 | 陈述、论证及其关系组成的图 |
| statement | 陈述 | 可被支持、反对或作为前提使用的命题 |
| premise | 前提 | 论证所依赖的陈述 |
| conclusion | 结论 | 某一论证支持或反对的陈述 |
| issue | 争点 | 需要在若干立场之间评估的问题 |
| position | 立场 | 争点中的候选陈述 |
| assumption | 假设 | 在给定模型中暂时接受的陈述 |
| presumption | 推定 | 在特定论辩语境下默认成立、可被反驳的前提 |
| exception | 例外 | 阻止论证型式适用的条件 |
| undercutter | 截断者；底切者 | 攻击前提到结论之间的推理连接 |
| rebuttal | 反驳 | 通过支持相反结论进行攻击 |
| argument scheme | 论证型式 | 可复用的实质性推理模板 |
| critical question | 批判性问题 | 检验论证型式适用性的标准问题 |
| burden of production | 提出证据责任 | 提出足够材料使争点进入评价的责任 |
| burden of persuasion | 说服责任 | 使争点达到适用证明标准的责任 |
| proof standard | 证明标准 | 在模型中决定陈述可接受性的评估标准 |
| preponderance of evidence | 优势证据标准 | Carneades 中缩写为 `PE` |
| clear and convincing evidence | 清楚且有说服力的证据标准 | Carneades 中缩写为 `CCE` |
| beyond reasonable doubt | 排除合理怀疑 | Carneades 中缩写为 `BRD` |
| weighing function | 权重函数 | 计算论证相对权重的函数 |
| labelling | 标记结果 | 将陈述标记为 `in`、`out` 或 `undecided` |
| in | 可接受 | 仅表示当前形式模型中的状态 |
| out | 不可接受 | 仅表示当前形式模型中的状态 |
| undecided | 未决 | 当前模型无法确定 |

## 翻译原则

1. 优先保留计算论证领域已经稳定使用的术语。
2. “证明责任”必须标明是论证理论含义还是诉讼法含义。
3. `weight` 不译为“事实概率”或“有罪概率”。
4. `in`、`out` 不译为“事实为真”和“事实为假”。
5. `undercutter` 在界面中使用“截断者”，文档首次出现时同时注明“底切者”。
